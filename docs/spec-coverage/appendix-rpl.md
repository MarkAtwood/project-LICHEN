## spec/appendix-rpl.md — coverage (sweep 2026-09-09)

Scope: the appendix is a pointer sheet delegating all normative RPL content to
`spec/drafts/draft-lichen-rpl-lora-00.md`. No separate sweep exists for that draft,
so this matrix covers (A) the appendix's own five checkable claims (R-RPL-001..005)
and (B) the draft's normative requirements (R-RPL-006..040), swept across all three
stacks (Rust `rust/lichen-rpl/` + `rust/lichen-node/src/rpl_stack/` + `rust/lichen-node/src/routing/`,
C `lichen/subsys/lichen/rpl/`, Python `python/src/lichen/rpl/`). Requirement IDs use
`R-RPL-NNN`, matching the R-SCHC/R-BR appendix convention. Related rows already swept
in depth: R-05-038/053/056/059/082, R-06-001/009/010/301/305/329 (docs/spec-coverage/05-routing.md,
06-security*.md) — cross-referenced, not re-adjudicated.

Step 0: no decision in `spec/decisions.jsonl` lists `appendix-rpl.md` (or the RPL draft)
in `specs`, so no verify-grep was mandatory for this section. Two settled decisions
govern behavior swept here and were honored, not re-adjudicated:
`unicast-dio-admission` (multicast-only DIO delivery; draft §6.4 "Targeted DIS:
unicast response" text conflicts with it — flagged F5, not fixed: the decision's
`verify` target is `rust/.../transmit.rs`, not this section) and `trickle-imax-1024s`
(draft §6.1 "17.5 minutes" table cell conflicts with the decision's 1024 s and with
the draft's own §6.2 math — flagged F6). `upstream-yggdrasil-addressing` is respected:
draft §7.1/§9.3 and all three stacks use `0200::/8` `AddrForKey` identity (R-RPL-024/033).
