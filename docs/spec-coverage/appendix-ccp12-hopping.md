`verify.grep_absent "Density > 8"` on spec/02a-coordinated-capacity.md
passes (no match), and this appendix consistently uses `Density > 10`

this section. Note: the ccp16.json vector **descriptions** still say

bead project-LICHEN-worker6-b7z9.180).

generated with **NChannels=3** (documented only in
python/tests/test_channel_plan.py:275-277 "ccp16.json was generated with
